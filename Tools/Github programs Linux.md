| Инструмент             | Что делает                                 | Когда использовать            |
| ---------------------- | ------------------------------------------ | ----------------------------- |
| **LinPEAS**            | Максимальный охват, выделяет важное цветом | CTF, быстрый аудит            |
| **LinEnum**            | Лёгкий и базовый, структурированный вывод  | Старые системы, быстрый чек   |
| **LES**                | Проверяет только ядро и CVE                | Подбор kernel exploit         |
| **Linux Smart Enum**   | Тихий, с уровнями глубины (-l 0–2)         | Реальные пентесты, скрытность |

LinPeas - [https://github.com/carlospolop/privilege-escalation-awesome-scripts-suite/tree/master/linPEAS](https://github.com/carlospolop/privilege-escalation-awesome-scripts-suite/tree/master/linPEAS)
- **Что делает:**
    
    - Самый популярный и мощный скрипт для перечисления.
        
    - Проверяет кучу векторов: SUID, sudo, cron, PATH, переменные окружения, ядро, капабилити, Docker, LXD и др.
        
    - Выводит результат в цвете, выделяя **красным самые опасные находки**.
        
- **Для чего используется:**
    
    - Быстро понять, где слабые места.
        
    - Особенно полезен в CTF (TryHackMe, HackTheBox).
        
- **Минусы:**
    
    - Очень шумный (долго работает, много выводит).
        
    - Может быть заметен для IDS/мониторинга.

**Пример применения:***
`./linpeas.sh`

## 2. **LinEnum**

👉 [GitHub: LinEnum](https://github.com/rebootuser/LinEnum)

- **Что делает:**
    
    - Старый, но простой инструмент для перечисления.
        
    - Проверяет базовые вещи: ядро, SUID, sudo, cron, сетевые сервисы.
        
    - Даёт структурированный вывод.
        
- **Для чего используется:**
    
    - Лёгкий и быстрый аналог LinPEAS.
        
    - Подходит для старых систем, где другие скрипты не работают.
        
- **Минусы:**
    
    - Не такой полный, как LinPEAS.
        

**Пример применения:**

`./LinEnum.sh`
## 3. **LES (Linux Exploit Suggester)**

👉 [GitHub: LES](https://github.com/mzet-/linux-exploit-suggester)

- **Что делает:**
    
    - Сравнивает твою версию ядра с известными уязвимостями.
        
    - Предлагает список CVE + ссылки на эксплойты.
        
- **Для чего используется:**
    
    - Быстро определить, уязвимо ли ядро для CVE.
        
    - Сэкономить время на ручном гугле.
        
- **Минусы:**
    
    - Проверяет только ядро, не ищет другие векторы (sudo, SUID).
        

**Пример применения:**

`./linux-exploit-suggester.sh`
## 4. **Linux Smart Enumeration (LSE)**

👉 [GitHub: LSE](https://github.com/diego-treitos/linux-smart-enumeration)

- **Что делает:**
    
    - "Умное перечисление".
        
    - Делает меньше проверок, чем LinPEAS, но более тихо.
        
    - Есть уровни (Level 0–2), где можно регулировать глубину проверки.
        
- **Для чего используется:**
    
    - Когда нужно работать скрытно, без огромного вывода.
        
    - Удобно на реальных пентестах, где лишний шум не приветствуется.
        

**Пример применения:**

`./lse.sh -l 2`

(`-l 2` → самый подробный уровень).
## 5. **Linux Priv Checker**

👉 [GitHub: Linux Priv Checker](https://github.com/linted/linuxprivchecker)

- **Что делает:**
    
    - Простой Python-скрипт.
        
    - Ищет очевидные векторы: конфиги, SUID, sudo, слабые права.
        
    - Даёт отчёт в стиле "чек-листа".
        
- **Для чего используется:**
    
    - Хорош для быстрого запуска, если есть Python.
        
    - Подходит новичкам, чтобы видеть основные направления.
        
- **Минусы:**
    
    - Меньше возможностей, чем у LinPEAS.
