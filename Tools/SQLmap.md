
> [!info] Определение
> Инструмент для автоматизации поиска SQL инъекций 

---

> [!vuln] Использование
```
sqlmap -u адрес_сайта
```

Рассмотри следующее: 
есть сайт с о страницей где указывается явная переменная, например 
`http://example_site/shop.php?id=8&productsId=12` здесь используются два параметра, `id` и `productId` и явно указанные данные напрямую забиваем 
> [!detect] Пример 
```
sqlmap -u http://example_site/shop.php?id=8&productsId=12 -p id
```
здесь мы дополнительно указали по какому параметру на следует искать инъекцию и в параметре `id` 
`--dbs` - параметр который позволяет извлечь список баз данных 
`--tables` - позволяет узнать список таблиц в конкретной базе данных
`--columns` - вытянуть колонки из таблицы
`--random-agent` - выбирает рандомный User-Agent для обхода WAF без него:
```
User-Agent: sqlmap/1.9.8#stable (http://sqlmap.org)
```
`--batch` - отвечать на все вопросы да
`--level=1-5` - глубина проверки 1 - проверка только GET и POST, 2 - +проверка Cookie, 3 - +User-Agent и Referer
`--risk=1-3` - опасность запросов, 1 - безобидные, 2 + timebased, 3 + запросы которые меняют данные 
`--os-shell` - запустить шел
`--data` - POST данные
`--method` - указать метод
`--ignore-code=403` - игнорировать определенный код ответа, здесь 403
`--threads` - количество потоков
`--tamper` - обфускация запросов с использованием скриптов 
	`between` - Заменяет `OR 1=1` на `OR 1 BETWEEN 1 AND 1`
	`randomcase` - Меняет регистр символов (`SELECT` → `sELEct`)
	`space2comment` - Заменяет пробелы на комментарии (`/**/`)
	`space2plus` - Пробелы на `+`
	`charunicodeescape` - Юникод-escape (`\u0027` вместо `'`)
	`equaltolike` - `=` заменяется на `LIKE`
	`percentage` - Экранирует спец. символы с `%`
