SPF: что это и как работает?

ender Policy Framework — DNS TXT-запись, содержащая IP-адреса разрешённых серверов-отправителей. Принимающий сервер проверяет: IP отправителя совпадает с SPF-записью домена из поля MAil FROM, если совпало с ip отправителя то SPF проверка проходит

Формат: v=spf1 ip4:1.2.3.4 include:google.com -all (-all = остальных отклонять). Предотвращает IP-спуфинг.

----

DKIM: что это и как работает?

DomainKeys Identified Mail — цифровая подпись письма. Отправитель подписывает хэш письма приватным ключом. Публичный ключ в DNS (TXT запись: selector._domainkey.domain). Получатель проверяет подпись. Сохраняется при пересылке в отличие от SPF. Подтверждает что письмо не изменено в пути.

---

DMARC: что это и что добавляет?

Domain-based Message Authentication, Reporting and Conformance. Политика для SPF/DKIM: что делать если проверки не прошли. DMARC отправляет DNS запрос к домену казанному в From, то есть он берет проверку SPF проверяет с From даже если SPF прошел, а значение MAiL FROM не совпадает с From, в этом случае SPF не прошла. В случае с DKIM сравнивает доменное имя отправителя в подписи с заголовком FROM если совпадает и DKIM прошел тогда DMARC выдаст PASS

 Запись: v=DMARC1; p=reject; rua=mailto:reports@domain.com. p=none (мониторинг), p=quarantine (спам), p=reject (отклонить). Требует выравнивания домена From: с SPF/DKIM.

DNSBL это и для чего нужен

DNSBL - это сервис где с помощью DNS запроса можно проверить является ли IP адрес источником рассылки спамам по электронной почте
Принцип работы:
На сервер приходит письмо от другого сервера с IP 111.222.33.44 
Сервер настроенный на работу с блокк листом делает DNS запрос вида

reverse-ip.BLNAME.DNSBLProvider.TLD

Например 
44.33.222.111.bl.spamcop.net
Далее в зависимости от ответа сервер принимает решение

Если ответ "NXDOMAIN" этот IP чист и спам с него не замечен
Если ответ - любой IP - значит адрес занесен в список и письмо принимать не стоит
В зависимости от списка блокировки, IP может обозначать причину занесения адреса в BL или не означать

SURBL что это

SURBL - представляет собой набор списков URI DNSBL, то есть проверяет вложенные ссылки по URL на их принадлежность незаконной деятельности: http://www.surbl.org/surbl-analysis - пример сайта для проверки

GreyListing что это и как работает

Способ проверки письма, когда сервер получателя отвечает ошибкой 450 SMTP которая означает что принять сейчас не может и нужно выслать ее раз, в результате спам бот игнорирует это сообщение а легитимное письмо отправится еще раз через какое то время

Локальные и глобальные Black\White листы

При добавлении в белый список письма приходят всегда даже если содержат вредоносное вложение - это адресная книга пользователя
Локальный черный список - пользователь сам добавил отправителя туда и пометил как спам
Глобальный черный список - попадают адреса если их отметили пользователи как спам

System что за процесс какой PID, кем запускается

Процесс System - это среда для особого типа потоков, которые работают только в режиме ядра - системных потоков режима ядра. PID всегда 4

Признаки компрометации процесса:
- Родительский процесс кроме System idle Process(0)
- Несколько экземпляров процесса
- Другой PID 
- Не запущен в 0 сессии

smss.exe — что это и норма?

Session Manager Subsystem. 
Первый процесс пользователя после boot. 
Родитель: System (PID 4). 
Путь C:\\Windows\\System32\\smss.exe. 
Запускает: csrss.exe и wininit.exe в 0 сессии и csrss.exe и winlogon.exe в сессии 0, копирует себя в новую сессию и самозавершается 

Аномалии: другой путь, несколько экземпляров (должен быть один), неправильный родитель.

Запускается так же любая другая подсистема указанная в поле `Required` в файле:
`HKLM\System\CurrentControlSet\Control\Session Manager\Subsystems` 
Это ветка реестра в которой хранится список подсистем windows которые должны запускаться при создании новой cессии
