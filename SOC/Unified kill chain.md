Это новая концепция которая была разработана в 2017 года и признана дополнить другие цепочки атак, такие как ATT&CK от Lockheed Martin и MITRE

Цепочка состоит из 18 этапов от разведки до утечки данных и понимания мотивов злоумышленника. Для краткости эти этапы были сгруппированы в несколько областей

# Первая фаза это Initial FootHold
## Reconnaissance (Разведка, по MITRE TA0043)
Этот этап описывает методы которые используют для сбора информации о цели,  это может быть достигнуто за счет пассивной и активной разведки. Информация собранная на этом этапе используется для последующих

Информация может включать:
- Исследование того какие службы работают на машине(эта информация полезна этапе создания оружия и эксплуатации)
- Поиск списков контактов или списков сотрудников которые могут быть использованы для фишинга или социальной инженерии
- Поиск потенциальных утечек данных, которые могут пригодиться на более поздних этапах
- Понимание топологии сети и других сетевых систем так же может быть использовано для перенаправления атаки
## Weaponization (Вооружение по MITRE TA0001)
На этом этапе злоумышленник создает необходимую инфраструктуру для проведения атаки. Например создание сервера управления и контроля или системы способной перехватывать обратные оболочки и доставлять пейлоады

## Social Engineering (Социальная инженерия по MITRE TA0001)
Здесь злоумышленник может использовать сотрудников для манипулирования с целью выполнения действий которые помогут атаке. Например атака с применением социальной инженерии может включать в себя:

- Заставить пользователя открыть вредоносное вложение в фишинге
- Имитация веб страницы и получение от пользователя ввода кредов

## Exploitation (Эксплуатация по MITRE TA0002)
Этот этап описывает как злоумышленник использует уязвимости которые присутствуют в системе

- Загрузка и выполнение веб шела
- Вмешательство в автоматизированный скрипт в системе для исполнения кода
- Злоупотребление уязвимостью веб приложения для выполнения кода в системе

## Persistence (Устойчивость по MITRE TA0003)
Описывает методы для сохранения доступа к системе к которой был получен доступ

- Создание службы в целевой системе, которая позволит восстанавливать доступ
- Добавление целевой системы на сервер управления и контроля, где команды могут выполняться удаленно в любое время
- Оставление других форм бекдоров, которые срабатывают при определенном действии в системе

## Defence Evasion (Обход защиты по MITRE TA0005)
Наиболее ценный этап потому что используется для понимания методов используемых злоумышленником для обхода мер защиты, установленных в системе или сети, например

- Межсетевые экраны веб приложений
- Сетевые экраны приложений
- Антивирусные системы
- IDS и IPS

Фаза ценна потому что помогает сформировать ответные действия и предоставляет оборонительной команде информацию о том как она может улучшить свои системы защиты
## Command&Control (Управление и контроль по MITRE TA0011)
Объединяет усилия предпринятые противником на этапе вооружения для установления связи между противником и целевой системой противник может установить командование и управление целевой системой для достижения своих целей, например 

- Выполнять команды
- Красть учетные данные и другую информацию
- Использовать сервер для перехода дальше по сети

## Pivoting (Переход по MITRE TA0008)
Фаза используемая для перехода к другим системам в сети, которые недоступны иным образом, то есть перемещение по внутренней сети цели 

# Вторая фаза Through (Network Propagation)
## Discovery (Исследование по MITRE TA0007)
злоумышленник будет собирать информацию о системе и сети к которой она подключена, будет формироваться база знаний на основе активных учетных записей пользователей предоставленных разрешений, используемых приложений и программного обеспечения, активности веб браузера, файлов, каталогов и сетевых ресурсов а также конфигураций системы
## Privilege Escalation (Повышение привилегий по MITRE TA0004)
после сбора злоумышленник попытается получить более высокие права доступа в системе. Они будут использовать информацию об учетных записях с обнаруженными уязвимостями и неправильными настройками для повышения своего доступа до одного из следующих уровней

- SYSTEM/ROOT
- Local Administrator
- Аккаунт с права админа
- Учетная запись с повышенными правами
## Execution (Исполнение по MITRE TA0006)
Развертывают вредоносный код используя закрепленную систему в качестве хоста. Развертываются и создаются удаленные трояны для обеспечения постоянного присутствия в системе
## Сredetional Access (Доступ к кредам MITRE TA0006)
Работая вместе на этапе повышения привилегий злоумышленник будет пытаться украсть имена учетных записей и пароли различными методами, включая кейлоггинг и дамп учетных данных. Это затрудняет их обнаружение во время атаки поскольку они будут использовать легитимные учетные данные
## Lateral movement(Боковое перемещение по MITRE TA0008)
имея учетные данные и повышенные привилегии, злоумышленник будет стремиться перемещаться по сети и переходить на другие целевые системы для достижения своей основной цели. Чем незаметнее используемая техника, тем лучше

# И последняя 3 фаза это OUT
Она завершает процесс атаки и цели обычно направлены на нарушение триады CIA
## Collection (Сбор данных MITRE TA0009)
После поисков доступа и ресурсов противник будет стремиться собрать все ценные данные которые предоставляют интерес. Это в свою очередь поставит под угрозу конфиденциальность и приведет к следующему этапу атаки - эксфильтрации. основные целевые источники это диски, браузеры, аудио и видеофайлы
## Exfiltration (Эксфильтрация MITRE TA0010)
Для усиления компрометации противник будет стремиться украсть данные которые упакованы с использованием мер шифрования и сжатия, чтобы избежать обнаружения. Канал управления и туннель развернутые на предыдущих этапах будут полезны
## Impact (Воздействие MITRE TA0040)
Если противник попытается поставить под угрозу целостность и доступность данных, он будет манипулировать ими, прерывать их или уничтожать. Цель атаки заключается в нарушении бизнес процессов и операционной деятельности и может включать в сея удаление доступа к учетным записям, очистку дисков и шифрование данных, например с помощью программ вымогателей, взлома и DoS атак
## Object 
Обладая всей мощью и доступам к системам и сети, противник будет стремиться достичь своей стратегической цели атаки. Например если атака мотивирована финансовыми соображениями, он может попытаться зашифровать файлы и системы с помощью программ-вымогателей и потребовать выкуп за разблокировку данных. В других случаях злоумышленник может стремиться нанести ущерб репутации компании и опубликовать конфиденциальную информацию
