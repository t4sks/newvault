## 🧪 Тест для повторения

> [!question]- 1. Что такое NAT, какие виды, как влияет на расследование в SOC?
> Network Address Translation — подмена адресов при прохождении через шлюз. SNAT (подмена источника, выход в интернет), DNAT (подмена назначения, проброс портов), PAT/overload (много внутренних IP за одним внешним через порты). Для SOC: за одним внешним IP скрыто много хостов → нужен лог трансляций для атрибуции.

> [!question]- 2. Опиши TCP handshake и для чего флаг RST.
> SYN → SYN-ACK → ACK устанавливает соединение (синхронизация sequence numbers). RST — резкий обрыв соединения (отказ/сброс), в т.ч. признак закрытого порта при сканировании.

> [!question]- 3. Что такое MITM, три способа реализации, как детектить.
> Перехват/модификация трафика между сторонами. Способы: ARP spoofing, DNS spoofing, rogue access point, SSL stripping. Детект: дубли MAC↔IP в ARP-таблицах, gratuitous ARP, неожиданная смена сертификата, два gateway.

> [!question]- 4. Как работает DNS-туннелирование и его признаки?
> Данные кодируются в DNS-запросы/ответы (поддомены, TXT-записи) для C2/эксфильтрации в обход фаервола. Признаки: аномально длинные имена, высокая частота запросов к одному домену, много уникальных поддоменов, нетипичные TXT, всплески NXDOMAIN.

> [!question]- 5. По одной атаке на L2, L3, L4, L7.
> L2: ARP poisoning / MAC flooding. L3: IP spoofing / ICMP tunneling. L4: SYN flood / TCP hijacking. L7: SQLi / DNS spoofing / phishing.

> [!question]- 6. Что такое DMZ и зачем сегментация для SOC?
> Демилитаризованная зона — буферный сегмент между интернетом и внутренней сетью для публичных сервисов. Сегментация ограничивает латеральное движение: компрометация DMZ не даёт прямого доступа во внутренний периметр; помогает локализовать инцидент.

> [!question]- 7. Виды туннелирования (минимум 4).
> SSH-туннели (local `-L`, remote `-R`, dynamic `-D`/SOCKS), DNS-туннель, ICMP-туннель, HTTP(S)-туннель, GRE, IPsec.
