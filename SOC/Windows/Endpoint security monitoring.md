# SysInternals 
Инструменты Sysinternals представляют собой набор из более чем 70 инструментов для windows. Каждый из инструментов относится к одной из следующих категорий:

- File and Disk Utilities
- Networking Utilities
- Process Utilities
- Security Utilities
- System Information
- Miscellaneous

## TCPView
TCPView это программа которая показывает детальный листинг всех TCp и UDP конечных точек в системе, включающая локальные и удаленные адреса и состояние TCP соединений. TCP представляет более информативную и удобную версию программы Netstat. ![[Pasted image 20260620152707.png]]

## Process Explorer
Process Explorer состоит из двух субокон. Основное окно всегда показывает перечень текущих активных процессов, включая имена их учетных записей владельцев, тогда как информация отображаемая в нижнем окне зависит от режима работы Process Explorer: если он находится в режиме дескрипторов вы увидите дескрипторы, которые открыл процесс выбранный в верхнем окне, если Process Explorer находится в режиме DLL, вы увидите DLL файлы и файлы отображаемые в память , которые загрузил процесс.![[Pasted image 20260620153055.png]]

Process explorer позволяет проверять такие детали запущенных процессов как:

- Связанные службы
- Вызванный сетевой трафик
- Открытые дескрипторы, такие как файлы или каталоги
- Загруженные DLL файлы и файлы отображаемые в память

# Windows Event logs
Обычно файлы расположены в `C:\Windows\System32\winevt\Logs`

Есть три основных путя доступа к логам в системе Windows
1. Event Viewer (GUI-Based)
2. Wevtutil.exe (Command-line tool)
3. Get-WinEvent (powershell cmdlet)


## Sysmon
приложение используемое для мониторинга и записи событий Windows, обычно используется предприятиями как часть их мониторингового и логирующего решения. Как часть Windows Sysinternals пакета, Sysmon очень похож на Windows Event Logs вместе с  более подробной информацией и детальным контролем

Sysmon собирает детализированные журналы а так же трассировку событий, помогая выявлять аномалии в вашей среде. Он обычно используется с SIEM или другими решениями для анализа журналов, которые агрегируют фильтруют и визуализируют события

Sysmon включает 27 типов идентификаторов событий, каждый из которых может быть использован в необходимом конфигурационном файле для указания того, как события должны обрабатываться и анализироваться. ![[Pasted image 20260620154135.png]]
