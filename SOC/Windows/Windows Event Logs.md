# Элементы Windows Event Logs

- System Logs - записи событий связанный с операционной системой. Они могут включать информацию об изменении аппаратного обеспечения, драйверов устройств, системных изменениях и других активностях происходящих на устройстве
- Security Logs - записи событий связанные с входом и выходом из системы на устройстве. Политика аудита определяет эти события. Логи прекрасный источник для аналитика чтобы изучить попытки успешных несанкционированных действий
- Application Logs - Записи событий связанные с установленными приложениями в системе. Основные куски информации включают ошибки приложений, события и предупреждения
- Directory Service Events - AD изменения и действия записываются в эти журналы, обычно на контроллерах домена
- File Replication Service Events - записи событий связанные с серверами Windows, в процессе распространения групповых политик и скриптов входа на контроллеры домена, откуда они становятся доступны пользователям через клиентские серверы 
- DNS Event Logs - DNS сервера используют эти логи для записи доменных событий и для составления карты
- Custom Logs - события логируются приложениями который запрашивают собственное хранилище данных. Это позволяет приложениям контролировать размер логов или настраивать другие параметры, такие как ACL's в целях безопасности.

В рамках этой классификации журналы событий можно дополнительно разделить на типы. Здесь типы описывают действия, которые привели к регистрации события. Существует 5 типов события, которые могут быть зарегистрированы как описано ниже

| Тип события                  | Описание                                                                                                                                                                                                                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ошибка (Error)               | Событие, указывающее на серьёзную проблему — например, потерю данных или утрату функциональности. Если служба не загружается при запуске, фиксируется событие типа «Ошибка».                                                                                                              |
| Предупреждение (Warning)     | Событие, не обязательно критичное, но указывающее на возможную проблему в будущем. Например, при нехватке места на диске фиксируется «Предупреждение». Если приложение способно восстановиться без потери данных или функциональности, событие, как правило, классифицируется именно так. |
| Сведения (Information)       | Событие, описывающее успешную работу приложения, драйвера или службы. Например, при успешной загрузке сетевого драйвера может быть записано событие «Сведения». При этом для настольных приложений запись такого события при каждом запуске считается избыточной.                         |
| Аудит успеха (Success Audit) | Событие, фиксирующее успешную попытку доступа в рамках аудита безопасности. Например, успешный вход пользователя в систему записывается как «Аудит успеха».                                                                                                                               |
| Аудит отказа (Failure Audit) | Событие, фиксирующее неудачную попытку доступа в рамках аудита безопасности. Например, если пользователь пытается подключиться к сетевому диску и получает отказ, попытка записывается как «Аудит отказа».                                                                                |
Есть три основных способа получить доступ к логах в Windows
1. Windows Viewer (eventvwr.msc)
2. Wevtutil.exe
3. Get-WinEvent
