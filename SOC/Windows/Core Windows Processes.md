# System
PID процесса всегда равен 4!!!

> [!note] Определение
> Процесс System - это среда для особого типа потоков, которые работают только в режиме ядра - системных потоков режима ядра. Системные потоки обладают всеми атрибутами и контекстами обычных потоков пользовательского режима, но отличаются тем что они работают только в режиме ядра, выполняя код, загруженный в системное пространство, будь то Ntosktln.exe или любой другой загруженный драйвер устройства. Кроме того системные потоки не имеют адресного пространства пользовательского процесса и следовательно должны выделять любое динамическое хранилище из куч памяти операционной системы, например страничный или нестраничный пул

# SSMS.exe Session Manager Subsystem
Процесс так же известный как Windows Session Manager отвечает за создание новых сессий это первый user-mode процесс запускаемый ядром

Этот режим запускает режимы ядра и пользовательского режима подсистемы windows. Эта подсистема включает win32k.sys (режим ядра), winsrv.dll (пользовательский режим) и csrss.exe (пользовательский режим)

Smss.exe запускает csrss.exe (Подсистема Windows) и wininit.exe в сессии 0 изолированной сессии Windows для операционной системы и csrss.exe и winlogon.exe для сессии 1, которая является пользовательской сессией. Первый дочерний экземпляр создает дочерние экземпляры в новых сессиях, что осуществляется путем копирования smss.exe самого себя в новую сессию и самозавершения.

`HKLM\System\CurrentControlSet\Control\Session Manager\Subsystems`

# CSRSS.exe

> [!note] CSRSS.exe
> CSRSS.exe - Client Server Runtime Process - это пользовательская часть подсистемы windows. Этот процесс постоянно запущен и критически важен для работы системы. Если он будет завершен, это приведет к сбою системы. Этот процесс отвечает за создание и удаление окон консоли Win32, а так же потоков процесса. Для каждого экземпляра процесса загружаются библиотеки csrsrb.dll, basesrv.dll, winsrv.dll и ряд других

Так же процесс выполняет следующие функции:

- Предоставляет другим процессам доступ к Windows API
- Сопоставляет буквы дисков (Например `C:`, `D:`) с соответствующими устройствами
- Участвует в обработке процедуры заверения работы Windoiws

# Explorer.exe

> [!NOTE] Explorer.exe 
> Windows Explorer, explorer.exe. Этот процесс дают пользователю доступ к его папкам и файлам. Он так же отвечает за функциональность для других функций, таких как начальное меню и Taskbar
> 
> Так же процесс winlogon.exe запускает userinit.exe который запускает программу указанную в
> `HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell` - по умолчанию в этом параметре указано explorer.exe
> После запуска explorer.exe процесс userinit.exe завершает свою работу. Поэтому если посмотреть дерево процессов позже, у explorer.exe не будет существовать родительского процесса, поскольку userinit.exe уже завершился

У explorer обычно много дочерних процессов потому что, через него пользователь запускает программы открывает папки, документы и другие приложения
