
> [!NOTE] Определение
> Реестр - иерархическая база данных в которой хранятся настройки и параметры, необходимые для работы Windows и установленных приложений

Реестр используется для:

- Хранения конфигурации системы и пользовательских настроек
- Управления установленным программным обеспечением
- Контроля за работой оборудования и драйверов
- Реализации политик безопасности
- Автозагрузки приложений и служб

Без реестра операционная система не сможет корректно работать так как там хранятся все необходимые данные

Изменения реестра могут повлиять на:

- Включение и отключения функций системы
- Менять параметры безопасноти
- Управлять работой сетевых служб
- Контролировать доступ пользователей к ресурсам

Важность реестра объясняет интерес атакующих к нему. Доступ позволяет атакующему:

- Получить конфиденциальную информацию 
- Изменять настройки системы для обхода защиты
- Установить malware


# Структура реестра

Реестр разделен на несколько корневых кустов

1 HKEY_CLASSES_ROOT (HKCR)
- Информация о зарегистрированных типах файлов и их ассоциациях с программами
- Используется для управления COM-объектами и ActiveX
2 HKEY_CURRENT_USER (HKCU) 
- Хранит настройки для текущего пользователя, такие как персонализация, параметры рабочего стола и установленного ПО
- Уникален для каждого пользователя 
- Единственное что доступно для редактирования без прав локального админа
3 HKEY_LOCAL_MACHINE (HKLM)
- Глобальные настройки системы, общие для всех пользователей
- Включает в себя данные о железе, драйверах, установленных программах и системных конфигурациях
4 HKEY_USERS (HKU)
- Хранит настройки всех пользователей, зарегистрированных в системе
- Каждый пользователь представлен уникальным SID
5 HKEY_CURRENT_CONFIG (HKCC)
- Информация о текущей конфигурации оборудования, которая используется при загрузке реестра

# Пример целей атакующего в реестре 

1 Хранение конфиденциальной информации
- В реестре могут хранится пароли, хэши, ключи шифрования(DPAPI) `HKLM\SECURITY\policy\Secrets`
2 Управление поведением системы
- Настройка автозапуска `HKLM\Sofware\Microsoft\Windows\CurrentМersion\Run` или `RunOnce`
- Отключать защитные механизмы системы или добавлять исключения `HKLM\SOFWARE\Microsoft\Windows Defender\Exlusion`
- Модифицировать системные параметры для обхода безопасности, например WDigest позволит хранить пароли в открытом виде `HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest`
3 Закрепление 
- Можно создавать задачи для планировщика задач через реестр: `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\TaskCache\Tasks` 
4 Privilege Escalation
- запускать любой файл `.msi` от SYSTEM если обе политики(`HKCU` и `HKLM`) выставлены в 1 независимо от прав текущего пользователя `HKLM\SOFWARE\Policies\Microsoft\Windows\Installer` 
- Modife imagePath для изменения ключа службы, мы можем изменить адрес службы на свой бинарник `HKLM\SYSTEm\CurrentControlSet\Services\<service>`
- Unquoted servicepath - если ImagePath без кавычек и содержит пробелы, Windows пытается интерпретировать каждый пробел как разделитель, если у атакующего есть право на запись в одну из промежуточных каталогов то просто кладет туда файл с нужным именем
