Пример команды для поиска в логах через конвейер команд

```
cat firewall.log | grep "BLOCK" | cut -d' ' -f5 | cut -d: -f1 | sort -nr | uniq -c
```

Читаем логи файрвола, выделяем все где указано слово BLOCK, cut разделяет по пробелу и забирает 5 строку, следующий cut берет разделение уже по : и забирает первую строку, сортируем по убыванию, где -n флаг включения числовой сортировки а -r флаг обратной, uniq -c оставляет только количество уникальных записей указывая количество их встречаемости для соседних строк

# Внешнее сканирование
При внешем сканировании мы видим внешний IP который проверяет нашу организацию, этот тип сканирования показывает, что атакующий находится на этапе разведки, и что он еще не закрепился в сети.![[Pasted image 20260605182006.png]]

Этот тип сканирования это начальная фаза атаки и атакующий еще не имеет входа во внутреннюю сеть поэтому это сканирование низкой степени тяжести. Как ответ на активность указывающую на внешнее сканирование сок аналитик может заблокировать IP с помощью firewall. Однако мы должны помнить что атакующий может вернуться и замаскировать свой IP адрес
# Internal Сканирование
Другой тип сканирования с которым можно столкнуться это внутреннее сканированием. Сок аналитик будет видеть что сканирование происходит с внутренних адресов организации. Этот тип сканирования начинается изнутри организационной и сканирует эту же сеть. Этот тип сканирования указывает на то что атакующий перешел в этапу Discovery по MITRE ATT&CK. В других фреймворках это так же будет называться внутренней разведкой, и это указывает на то что атакующий имеет доступ в сеть и сейчас ищет способ для перемещения по ней
![[Pasted image 20260605182710.png]]
Это высоко критичный alert. Убедившись что это незаконная деятельность внутри сети аналитик передаст оповещение вышестоящему и запустит процесс реагирования на инцидент. В этом случае простой блокировки исходного IP будет недостаточно
# Горизонтальное сканирование
Сканирование одинакового порта на разных хостах называется горизонтальное сканирование
Для обнаружения мы можем использовать тот факт что с одного IP идет сканирование одного порта назначения для разных IP.

# Вертикальное сканирование
Это когда происходит сканирование одного IP по списку портов. Используется атакующим для определения сервисов на машине. Такая активность должна появиться когда атакующий фокусируется на идентификации уязвимости на одной конкретной машине, потому что эта машина имеет интерес для атакующего. Например если организация предоставляет доступ в интернет только одному серверу, любой злоумышленник желающий проникнуть в эту организацию сначала выполнит вертикальное сканирование этого сервера, чтобы выявить открытые порты и понять, какие службы работают на этой машине
![[Pasted image 20260605184723.png]]
Можем увидеть такое сканирование если в логах много одного IP который сканирует один IP но с разными портами.
