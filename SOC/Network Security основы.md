Пример команды для поиска в логах через конвейер команд

```
cat firewall.log | grep "BLOCK" | cut -d' ' -f5 | cut -d: -f1 | sort -nr | uniq -c
```

Читаем логи файрвола, выделяем все где указано слово BLOCK, cut разделяет по пробелу и забирает 5 строку, следующий cut берет разделение уже по : и забирает первую строку, сортируем по убыванию, где -n флаг включения числовой сортировки а -r флаг обратной, uniq -c оставляет только количество уникальных записей указывая количество их встречаемости для соседних строк
