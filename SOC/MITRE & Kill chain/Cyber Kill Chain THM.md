# Разведка 
Этап исследования и планирования атаки на жертву или систему. Злоумышленники используют этот этап для сбора информации о своей цели, чтобы определить свои дальнейшие действия, эта информация может включать в себя детали инфраструктуры, данные о сотрудниках, бизнес процессы и уязвимые технологии.

## Типы разведки
Пассивная - Отсутствие прямого взаимодействия с целью. Поиск данных взаимодействия с целью

Активная - предполагает прямой контакт с целью с помощью таких действий как социальная инженерия, сканирование портов, захват баннеров или поиск открытых сервисов

# Weaponization 
На этапе вооружения злоумышленник может использовать следующие тактики: 

- Создать зараженный MS Word содержащий вредоносные макросы или скрипты VBA
- Создать вредоносную полезную нагрузку или очень сложный червь, внедрить его на USB накопители, а затем распространить в открытом доступе

То есть это этап создания или поиск полезной нагрузки для атаки на цель

# Delivery
Это процесс в ходе которого выбирается метод передачи пейлоада в целевую среду.

Существует множество вариантов, например

- Фишинговые письмо на организацию или конкретное лицо
- USB накопители
- Атака типа "Watered Hole" нацелена на определенную группу людей путем компрометации веб сайта, который они обычно посещают, перенаправляя их на вредоносный вебсайт по выбору атакующего 

# Explotation
Это момент когда код злоумышленника выполняется на целевой системе, используя известную уязвимость. На этапе может использоваться ряд ключевых методов для получения доступа

- Выполнение вредоносных макросов - осуществляется через фишинг
- Эксплуатация уязвимостей нулевого дня - эти уязвимости используют неизвестные или неустраненные недостатки в системе. На начальном этапе их невозможно обнаружить
- Известные CVE - злоумышленник может использовать неустраненные общедоступные уязвимости

Признаки эксплуатации:

- Неожиданное создание процессов
- Изменения в реестре или создание новых служб
- Подозрительные аргументы командной строки, обнаруженные в системных журналах

# Installation
закрепление - это установка постоянного бекдора в систему. постоянный бекдор позволит злоумышленнику получить доступ к системе которую скомпрометировали ранее

https://tryhackme.com/room/windowslocalpersistence комната где рассказывается про закрепление в windows

Постоянный способ может быть обеспечен с помощью например:

- Установки Веб оболочки на веб сервере
- Установка бекдора на машину жертвы с использованием Meterprenter
- Создание или изменение служб windows. Это метод T15443.003 в MITRE ATT&CK. Злоумышленник может создавать и изменять службы windows для регулярного выполнения вредоносных скриптов или полезных нагрузок в рамках обеспечения устойчивости. Например могут использоваться такие инструменты как `ssc.exe`, он позволяет создавать запускать останавливать или удалять любые службы Windows и `Reg` для изменения конфигураций служб. Злоумышленник может маскировать полезную нагрузку используя имя службы которое известно и связано с операционной системой или легитимным программным обеспечением. 
- Добавление записи в ключи запуска для вредоносной полезной нагрузки в реестре или в папке автозагрузки. Таким образом, полезная нагрузка будет исполняться каждый раз при входе в систему

Так же на этом этапе злоумышленник может использовать технику изменения временных меток, чтобы избежать обнаружения экспертом криминалистом и заставить вредоносное ПО выглядеть как часть легитимной программы. Техника изменения меток позволяет изменять временные метки включая дату создания, время изменения доступа и так далее

# Command and Control
После получения постоянного доступа и запуска вредоносного ПО на компьютере жертвы атакующий открывает канал управления и контроля через вредоносное ПО для удаленного управления и манипулирования жертвой. Этот термин так же известен как `C&C` или `C2 Beaconing` обозначающий тип вредоносной связи между сервером `C&C` и вредоносным ПО на зараженном хосте

Компрометированная конечная точка будет взаимодействовать с внешним сервером, созданным злоумышленником для установления канала управления и контроля. После установления соединения злоумышленник получает полный контроль над компьютером жертвы. 

Наиболее распространенные каналы контроля используемые злоумышленниками включают:

- HTTP на 80 порту и HTTPS на 443 где этот тип обмена смешивает вредоносный трафик с легитимным трафиком и может помочь брандмауэры
- DNS где зараженная машина постоянно отправляет DNS запросы на сервер принадлежащий злоумышленнику, это называется `DNS тунелированние`

# Actions And Objects 
Последний этап который подразумевает достижение цели

- Получение учетных данных пользователей
- Повышение привилегий(например расширенный доступ или доступ администратора домена)
- Провести внутреннюю разведку (например проверка внутреннего программного обеспечения на уязвимости)
- Перемещаться по внутренней среде компании
- Удалить резервные копии и теневые копии(Теневые копии это технология, которая позволяет создавать резервные копии или снимки файлов и томов компьютера)
- Перезаписать и повредить данные
