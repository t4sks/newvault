
# SSL Stripping

Уязвимость в самой архитектуре, когда пользователь вводит `example.com` без https:// браузер отправляет первый запрос по HTTP, сервер отвечает редиректом 302/301 на HTTPS версию. В этой точке соединение еще не зашифровано это и есть окно атаки. 

Для этой атаки можно использовать ssl-strip

Изначально атакующий уже находится между жертвой и сервером, например с помощью ARP спуфинга, в момент, когда клиент отправляет запрос он отсылает ему ответ заместо сервера, самостоятельно устанавливая соединение между сервером по https при этом общаясь с жертвой по HTTP.
