
[[Карта раздела Types Of Vulnerabilities in Web]]

> [!info] Определение
> уязвимость которая позволяет вмешиваться в запросы которые приложение делает к своей базе данных
 Позволяет злоумышленнику просматривать данные которые он обычно не может получить
Обычно это любая конфиденциальная информация, часто можно изменять или удалять данные, вызывая постоянные изменения в содержании 


# Карта раздела
[[Detect SQL injection]] - Наличие SQL инъекции
[[Все о бд при использовании SQL атак]] - извлечение типа, версии, таблиц и БД
[[SQL injection UNION attacks]] - атака с использованием UNION для получения данных
[[Blind SQL injection - слепое внедрение]] - атака через просмотр действий приложения, когда данные напрямую не извлекаются
[[Error-based SQL injection - SQL атака на основе ошибок]] - похожая на blind только тут мы используем выведение ошибок приложения как маркер отработки нашей инъекции, иногда ошибки помогают извлекать данные
[[Использование Blind SQL injection для временных задержек]] - получаем информацию о истинности выражения с помощью того через сколько отвечает сервер, причем временем управляем мы сами
[[Blind SQL с использованием OAST]] - использование связи дб с различными внешними DNS чтобы получать информацию
[[Внедрение SQL в разлинчых контекстах]] - используем необычные методы внедрения инъекции
