
> [!info] Определение
> уязвимость которая позволяет вмешиваться в запросы которые приложение делает к своей базе данных
 Позволяет злоумышленнику просматривать данные которые он обычно не может получить
Обычно это любая конфиденциальная информация, часто можно изменять или удалять данные, вызывая постоянные изменения в содержании
