#### Описание

> [!info] Описание
> Современные серверы при загрузке файла сначала загружают его во временное хранилище и присваивают новое рандомное имя чтобы избежать перезаписи файлов после выполняется проверка т только потом после того как его сочтут безопасным файл уходит по назначению
> Иногда разработчики реализуют свою проверку загружаемых файлов независимо от какой либо платформы, это очень сложно и часто приводит к гонкам которые позволяют злоумышленнику полностью обойти даже самую надежнуюпроверку

> [!note] Пример
> Некоторые веб сайты загружают файл непосредственно в файловую систему, а затем снова удаляют его если он не проходит проверку, и такое поведение характерно для серверов использующих антивирусное ПО или что то похожее для проверки файлов, это занимает всего несколько секунд но пока файл существует на сервере, злоумышленник может его запустить

Такие уязвимости малозаметны, и это усложняет их поиск когда тестируется blackbox, но если найти утечку кода, может быть получится сделать что то еще

#### Условие гонок при загрузку через URL

Гонки при загрузке файлов по URL-адресу могут возникать если сервер должен получить файл через интернет и создать локальную копию прежде чем он сможет выполнить какую то проверку, поскольку файл загружается через http, разработчик не может использовать встроенные механизмы платформы для безопасной проверки файлов, вместо этого они могут вручную создавать свои собственные процессы для временного хранения и проверки файла, что может быть не безопасным 
Например:
Если файл загружен во временный каталог с произвольным именем, злоумышленник теоретически не сможет воспользоваться условиями гонки, если он не сможет зхапросить файл, чтобы запустить его выполнение с другой стороны если рандомное имя каталога генерируется с использованием псевдослучайных функций, например: `uniqid()` в `php`, оно потенциально может быть обработано методом перебора
Для упрощения подобных атак можно попытаться увеличить время затрачиваемое на обработку файла, тем самым увеличив время необходимое для перебора имени каталога, один из способов это загрузить файл большого размера, если он обрабатывается фрагментарно, мы можем воспользоваться этим, создав вредоносный файл с полезной нагрузкой в начале, за которой следует большое количество произвольных байт
