#### Возможные вектора атак

> [!attention] НЕТ ПРОВЕРКИ ТИПА ИЛИ ОНА СЛОМАНА
> При несоблюдении ограничений приводит к тому что функция для загрузки картинки, может быть использована для загрузки опасных файлов, это могут быть скрипты, которые позволяют сделать RCE на стороне сервера, иногда для активации требуется HTTP запрос к файлу. В худшем случае веб приложение не может должным образом проверить тип загружаемого файла и если это .php .jsp то мы получаем вебшелл что дает нам управление сервером.
