#### Загрузка опасных скриптов для стороны клиента
Возможно мы не сможем выполнять скрипты на сервера, но мы все равно может загружать скрипты для атак на стороне клиента, Например если мы можем загружать `HTML-файлы`, или `SVG-изображения`, потенциально мы можем использовать теги `<script>` для создания и сохранения полезных XSS файлов
Если загруженный файл потом появится на странице которую посещают другие пользователи, их браузер выполнит сценарий при попытке отобразить страницу.

> [!warning] ВАЖНО
> Из за политик безопасности, подобные атаки будут эффективны в том случае если загруженный файл поступает из того же источника в который вы его загружаете
