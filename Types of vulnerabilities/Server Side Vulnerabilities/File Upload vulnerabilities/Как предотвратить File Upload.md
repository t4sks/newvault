
#### Наиболее эффективные методы:
- Сверяйте расширение файла с белым списком а не с черным
- Убедится что имя файла не содержит подстрок которые могут быть интерпретированы как каталог или последовательность обхода `../`
- Переименуйте загруженные файлы, чтобы избежать коллизии, которые могут привести к перезаписи уже существующих файлов
- Не загружайте файлы в постоянную файловую систему пока они полностью не проверены
- По возможности использовать структуру обработки файлов без попыток создания своих механизмов
