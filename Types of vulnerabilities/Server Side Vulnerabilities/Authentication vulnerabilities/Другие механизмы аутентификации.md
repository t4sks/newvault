## Сохранение состояния входа

> [!info] Основное
> Это позволяет сохранить сеанс даже если браузер закрыт, за это отвечает галочка запомнить меня или остаться в системе
> Функциональность часто реализуется с помощью  генерации токена "remember me" который после сохраняется в файле cookie. Так как наличие cookie файла позволяет эффективно обойти весь процесс входа в систему, рекомендуется сделать так, чтобы файл cookie было невозможно угадать, но некоторые веб приложения генерируют их на основе предсказуемых значений, таких как имя пользователя и метка времени, в некоторых случаях используется даже пароль. 
> Такой подход не является безопасным, если атакующий может создать собственную учетную запись и изучить свой cookie, разобравшись с методом его генерации. Разобравшись в формуле, он может попытаться подобрать куки других пользователей с помощью перебора, чтобы получить доступ к их аккаунтам

По сути некоторые сайты думают что cookie зашифрован а значит его невозможно угадать даже если он использует предсказуемые значения. Это может быть верно при корректной реализации, но шифрование cookie с помощью Base64, не дает никакой защиты, даже использование корректного шифрования однонаправленной хэш функции не является особенно надежным, если атакующий легко определит используемый алгоритм шифрования и при этом соль не применяется, потенциально можем перебрать cookie просто хэшируя словари с пользователями и паролями, так же этот метод позволит обойти лимиты и блокировки при брутфорсе
Даже если невозможно создать свою учетную запись можем воспользоваться такими методами как XSS, чтобы украсть файл Cookie другого пользователя и на его основе определить как он создан
Если веб сайт создан с использованием платформы с открытым исходным кодом, ключевые детали создания файла могут быть публично задокументированы
Иногда 
### Brute-forcing a stay-logged-in cookie пример лабы
указано что мы можем войти в свой профиль с помощью куки сохранения состояния, изучив куки стало понятно что оно зашифровано в base64 а сам вид имеет: `name:md5(password)`
тогда пишем программу для создания словаря с нужным нам форматом cookie 
```python
import hashlib  
import base64  
  
with open('passwords.txt', encoding="utf-8") as f:  
    for a in f:  
        a=a.strip()  
        md5hash=hashlib.md5(a.encode()).hexdigest()  
        data = f"carlos:{md5hash}"  
        base64result = base64.b64encode(data.encode()).decode()  
        print(base64result)
```
после этого запускам `intruder` с запросом типа `GET /my-account` а после ждем хотя бы один код 200 и забираем нужную нам cookie
