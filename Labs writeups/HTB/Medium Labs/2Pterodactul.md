начинать стоит с того что панель имеет версию 11.11.10  и находится по адресу  
```
panel.pterofactyl.htb
```
найти ее можно с помощью брутфорса поддоменов, на эту панель так же существует `CVE-2025-419132` которая дает LFI на любой разрешенный для пользователя файл в системе, этим можно легко воспользоваться если найти правильный эксплоит, так же если существует доступный на файловой системе PHP-скрипт `pearcmd.php` как примитив для записи файла/вставки PHP а затем можно подключить и исполнить написанное, из `phpinfo()` мы знаем что у нас есть путь `/usr/share/php/PEAR` + `register_argc_argv` стоит `on` так что RCE возможно, но LFI может внятно читать только формат json, для этого мы можем прочитать файлы 
```
http://target/locales/locale.json?locale=../../../pterodactyl&namespace=config/app конфиги приложения

GET http://target/locales/locale.json?locale=../../../pterodactyl&namespace=config/database
конфиги базы данных
```
эти два файла запарсятся нормально без особых проблем а вот чтобы читать другие файлы нужно делать это по другому
